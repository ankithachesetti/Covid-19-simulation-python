# COVID-19 Spread Simulation

## About the Project
This project simulates the spread of COVID-19 using a Markov Chain model.
It represents different health conditions and analyses how the disease
spreads through a population over time.

## Technologies Used
- Python
- Pandas
- Matplotlib
- Streamlit

## Project Structure
- assignment2.py - Main simulation program
- helper.py - Helper functions and plots
- sim_parameters.py - Simulation parameters
- streamlit_ui.py - Streamlit user interface
- test.py - Testing
- a2-countries.csv - Input dataset
